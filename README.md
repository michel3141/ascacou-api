# Ascacou — API

Composant API de la version web d'**Ascacou**, jeu de construction imaginé par
**Marc Buonomo** ([ascacou.com](https://www.ascacou.com/)) :
« Le jeu où la stratégie se mêle à la géométrie ».

## Le principe

Ascacou se joue à deux, en disposant chacun son tour les pions noirs et blancs sur le plateau.
Le gagnant est celui qui a reproduit le plus de cartes motif de son jeu.
